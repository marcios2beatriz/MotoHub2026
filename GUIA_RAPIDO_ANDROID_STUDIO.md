# 🚀 GUIA RÁPIDO - COMPILAR NO ANDROID STUDIO

## ⚡ **PASSO A PASSO SIMPLIFICADO**

### **1️⃣ Abrir Projeto (30 segundos)**
1. Abra **Android Studio**
2. **File → Open**
3. Selecione a pasta: `C:\Users\ectli\dyad-apps\moto-hub2026-3-1\android`
4. Clique **OK**
5. **Aguarde** a barra de progresso embaixo terminar

---

### **2️⃣ Configurar Java 17 (1 minuto)**
1. **File → Settings** (Ctrl+Alt+S)
2. Vá em: **Build, Execution, Deployment → Build Tools → Gradle**
3. Em **"Gradle JDK"**, selecione: **17** ou **jdk-17.0.20.101-hotspot**
4. **Apply → OK**

---

### **3️⃣ Limpar Cache (1 minuto)**
1. **File → Invalidate Caches / Restart...**
2. **Invalidate and Restart**
3. Aguarde reabrir

---

### **4️⃣ Clean + Rebuild (5 minutos)**
1. **Build → Clean Project** (aguarde terminar)
2. **Build → Rebuild Project** (aguarde até aparecer "BUILD SUCCESSFUL")

---

### **5️⃣ Gerar APK (2 minutos)**
1. **Build → Build Bundle(s) / APK(s) → Build APK(s)**
2. Aguarde notificação: "APK(s) generated successfully"
3. Clique em **"locate"** para abrir a pasta do APK

---

## 📍 **CAMINHO DO APK**
```
android\app\build\outputs\apk\debug\app-debug.apk
```

---

## ✅ **PRONTO!**
Copie o APK para o celular e instale!

**Tempo total:** ~10 minutos
